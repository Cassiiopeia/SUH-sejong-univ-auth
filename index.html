빠른 시작

Maven Central 이 아닌 SUH Nexus 저장소에서 제공합니다.

1. 저장소 추가

build.gradle
repositories {
    mavenCentral()

    // SUH Nexus 저장소 (필수)
    maven {
        name = 'SUH-NEXUS'
        url "https://nexus.suhsaechan.kr/repository/maven-releases/"
        metadataSources {
            mavenPom()
            artifact()
        }
    }
}
pom.xml
<repositories>
    <repository>
        <id>suh-nexus</id>
        <name>SUH Nexus Repository</name>
        <url>https://nexus.suhsaechan.kr/repository/maven-releases/</url>
    </repository>
</repositories>

2. 의존성 추가

build.gradle
dependencies {
    implementation 'kr.suhsaechan:sejong-univ-auth:1.2.7'
}
pom.xml
<dependency>
    <groupId>kr.suhsaechan</groupId>
    <artifactId>sejong-univ-auth</artifactId>
    <version>1.2.7</version>
</dependency>

3. 바로 사용

Java
@RestController
@RequiredArgsConstructor
public class AuthController {

    private final SuhSejongAuthEngine suhSejongAuthEngine;

    @PostMapping("/auth/sejong")
    public SejongAuthResult authenticate(@RequestParam String studentId,
                                         @RequestParam String password) {
        return suhSejongAuthEngine.authenticate(studentId, password);
    }
}

Spring Boot Auto Configuration 덕분에 별도 설정 없이 바로 사용할 수 있습니다.

주요 기능

SSO 인증

세종대학교 포털에 자동 로그인하고 복잡한 SSO 리다이렉트를 처리합니다. 로그인 실패는 즉시 감지합니다.

학생 정보 조회

학과, 학번, 이름, 학년, 상태(재학·휴학·졸업)를 조회합니다.

고전독서 인증 조회 (DHC)

영역별 인증 도서, 시험 응시 이력, 공모전 참가 이력을 조회합니다.

연락처 조회 (SIS)

이메일, 전화번호, 영어 이름을 조회합니다.

Spring Boot 자동 설정

생성자 주입으로 바로 쓰고, application.yml 로 세부 설정을 바꿉니다.

데이터 소스

데이터 소스도메인제공 정보
DHC (대양휴머니티칼리지)classic.sejong.ac.kr학생정보, 고전독서 인증
SIS (학사정보시스템)sjpt.sejong.ac.kr학생정보, 연락처(이메일, 전화번호)
조회 방식
// 통합 인증 (DHC + SIS 모두 조회)
SejongAuthResult result = authEngine.authenticate("학번", "비밀번호");

// DHC 전용 (고전독서 정보 보장)
SejongDhcAuthResult dhc = authEngine.authenticateWithDHC("학번", "비밀번호");
SejongClassicReading reading = dhc.getClassicReading();

// SIS 전용 (연락처 정보 보장)
SejongSisAuthResult sis = authEngine.authenticateWithSIS("학번", "비밀번호");
String email = sis.getEmail();

설정과 요구사항

application.yml 에서 세부 설정을 바꿀 수 있습니다.

application.yml
sejong:
  auth:
    ssl-verification: false    # SSL 검증 (기본: true)
    timeout-seconds: 10        # 타임아웃 초 (기본: 10)
    max-retry: 3               # 최대 재시도 횟수 (기본: 3)
세종대학교 포털의 SSL 인증서 문제로 ssl-verification: false 를 권장합니다.
