📝 현재 문제점
---

- Java/Spring만 지원해서 Python, Node를 쓰는 세종대 학생 개발자는 포털 로그인(SSO, 쿠키, HTML 파싱, 레거시 TLS)을 직접 구현해야 함
- 배포가 개인 Nexus라 사용자가 저장소 주소를 따로 추가해야 함

🛠️ 해결 방안 / 제안 기능
---

- 한 레포(모노레포)에서 Java, Python, Node를 함께 지원
- Python: PyPI `pip install pro-sejong-auth`, Node: npm `npm install pro-sejong-auth`, Java: Maven Central `kr.suhsaechan:sejong-univ-auth`
- 세 언어 같은 기능, 같은 결과 필드, 같은 에러 코드, 같은 버전 번호
- 포털 흐름, 결과 스키마, 응답 샘플을 `spec/` 한 곳에서 공유
- 설계: docs/superpowers/specs/2026-10-22-multi-language-monorepo-design.md
- 계획: docs/superpowers/plans/2026-10-22-multi-language-monorepo.md
